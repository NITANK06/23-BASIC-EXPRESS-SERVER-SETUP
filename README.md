# 23-BASIC-EXPRESS-SERVER-SETUP

A simple backend server built using Node.js and Express.js.  
This project demonstrates basic server setup, routing, middleware usage, static file serving, and API testing with Postman.



 Features

Express server setup
 GET routes
 POST route handling
 Static file serving
 Home, About, and Contact pages
 JSON request handling
 404 error handling
 Postman API testing collection
 Beginner-friendly backend project



 Tech Stack

 Node.js
 Express.js
 JavaScript (ES6)
